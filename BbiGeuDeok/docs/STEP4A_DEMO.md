# STEP 4-A — 보호된 외부 시연 경로

기존 로컬 Python 대시보드를 Cloudflare Quick Tunnel에 연결하는 선택적 시연 도구를 추가했습니다. 기존 서버는 `127.0.0.1:8766`을 유지하고 게이트웨이는 `127.0.0.1:8767`, 터널 메트릭은 `127.0.0.1:20245`만 사용합니다. 소스 공개와 실제 서비스 실행은 별개이며 이 저장소를 push해도 대시보드는 배포되지 않습니다.

## 접근 인증과 데이터 권리

이메일 제한 모드와 전용 링크 인증 모드를 지원합니다. 이메일 모드는 설치된 cloudflared의 `--allowed-mail` 옵션을 확인합니다. 인증 세션이 유지되지 않으면 실제 지도·API·Agent 사용 성공으로 처리하지 않습니다.

전용 링크는 256비트 난수 접속값을 URL 조각으로 전달합니다. 로그인 문서는 조각을 지운 다음 같은 출처의 인증 API에만 전송하고, 8시간의 Secure·HttpOnly·SameSite=Lax 세션 쿠키를 발급합니다. 인증 전에는 로그인 안내만 제공하고 데이터 API와 제품 자산을 차단합니다. 링크를 가진 사람이 접근할 수 있으므로 전체 링크는 인증 비밀값입니다. 공개 README·Git·로그·이슈에 넣지 않습니다.

실제 시연의 전송 승인은 Cloudflare를 통한 데이터 중계와 선택적인 Upstage 질문·도구 근거 전송을 포함해야 합니다. 사용자 테스트 승인은 주최 측 허가나 제3자 권리 확인을 의미하지 않습니다. 대회 데이터와 파생 지도·수치·응답의 외부 공유 권한은 여전히 미확인이며, 검토한 허용 범위를 넘어 공유하지 않습니다. 운영 공개나 대회 심사용 전환은 권리 확인이 필요합니다.

로컬 설정에서 `mode=dashboard`, `access_mode=secret_link`를 사용하려면 `team_test_authorization.approved_by_user=true`, `scope=SECRET_LINK_TEST`, 실제 승인 내용을 적은 `instruction`, 정확한 `relay=Cloudflare Quick Tunnel`과 `provider=https://api.upstage.ai`가 필요합니다. 해당 값은 실제 승인 범위와 일치해야 합니다. `allowed_emails=[]`이며 링크 보유가 접근 기준입니다. 권리 근거가 없는 경우 `data_rights.confirmed=false`, `third_party_content_reviewed=false`를 유지합니다. 예제는 이러한 승인을 미리 부여하지 않습니다.

## 보존한 경계

| 항목 | 적용 범위 |
|---|---|
| 프록시 | 고정 루프백 대상과 명시적 GET/POST 경로만 허용. 임의 URL·파일 경로는 전달하지 않음 |
| Host·Origin | 생성된 외부 HTTPS 호스트 하나만 허용. 검증 후 로컬 Host·Origin으로 전달하며 기존 백엔드 검사를 유지 |
| 전달 헤더 | 이메일·쿠키·Authorization·X-Forwarded 헤더를 백엔드 인증 근거로 전달하지 않음 |
| 세션·로그인 | 로그인 분당 10회, 세션 최대 50개. 질문·키·쿠키·접속값은 진단 로그에서 제외 |
| 요청 예산 | 동시 소켓 4개, Agent 1개, 분당 6질문. 실제 LLM 질문 누적 10개 예약을 파일로 보존하며 실패도 차감 |
| 공급자 예산 | 러너가 시작한 백엔드는 분당 6회·프로세스당 30회. 한 질문이 여러 공급자 호출을 사용하며 요금의 정확한 금액 상한은 아님 |
| 장애 대응 | 시작 전에 완료 캐시를 한 번 읽고, 15초마다 자식·로컬 상태 확인. 자식 종료나 3회 연속 응답 실패 시 소유 터널 종료. 자동 재시작·예산 초기화 없음 |
| 브라우저 | 인증 만료·리다이렉트를 명시적으로 안내하고 Agent POST를 자동 재전송하지 않음. 지도 타일에 출처 호스트를 전달하도록 Referrer 정책 조정 |

서버 호스팅 비용과 Upstage 과금·크레딧은 별개입니다. PC·터널 종료, 절전, 네트워크 장애가 외부 접속에 영향을 줍니다. Quick Tunnel은 주소가 바뀔 수 있으며 고정 URL·운영 SLA를 제공하지 않습니다.

## 검증 범위와 다음 단계

로컬 시연에서 외부 HTTPS 주소를 통한 5개 페이지, R/O/A 근거, SK 지도·월별 차트, 복지 검색, 정형 Agent 및 실제 Upstage Tool Calling과 후속 오류 복구를 확인했습니다. 별도 팀원 PC에서의 재현은 추가 확인 대상입니다. 실데이터 응답·검증 로그·스크린샷과 접속값은 공개 소스에 포함하지 않습니다.

GitHub Actions는 기존 Python 합성 테스트 10개, 게이트웨이 합성 테스트 16개, UI 상태 테스트 19개와 공개 manifest·Git index 검사를 수행합니다. CI는 실제 데이터, 외부 인증, 지도 타일, 공급자 응답이나 서버 생존을 재검증하지 않습니다.

기존 RUN-01의 일시적 무응답은 원인이 확정되지 않았습니다. 이번 감시는 장애 시 노출을 닫는 장치이며 원인 해결·운영 안정성 보증으로 간주하지 않습니다. 고정 HTTPS 주소는 후속 단계에서 Tailscale Funnel 및 무료 독립 호스팅을 비교합니다. 메모리 시작 피크, 영속 데이터·예산, TLS·인증, 재시작과 데이터 권리를 함께 검토해야 합니다.
