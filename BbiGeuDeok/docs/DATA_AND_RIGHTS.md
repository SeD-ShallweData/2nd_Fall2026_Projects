# 데이터 출처와 공개 범위

| 자료 | 원 출처·역할 | 이번 저장소 처리 |
|---|---|---|
| SK텔레콤 이동전화·이동 집계, 신한카드 | 2026 빅콘테스트 제공 자료. 카드 자료는 현재 SK 활동 탐색의 입력 목록과 구분 | 원본·정의서·집계·분석 결과 모두 제외. 대회 제출 허용을 재배포 허가로 간주하지 않음 |
| 관계망·R/O 표준화 및 통합표 | 별도 제공 분석 결과를 계약·해시로 고정해 정합성 대조 | 결과와 모든 파생 JSON/CSV 제외. 표준화 생성 코드·고정 가중치 미확보 |
| 서울시 참여 프로그램 | [OA-21309](https://data.seoul.go.kr/dataList/OA-21309/S/1/datasetView.do), `tbPartcptn` | API 구현·명세 정보만 포함. 원문·본문 이미지·로컬 복지 카탈로그·API 캐시 제외 |
| 서울시 복지 서비스 목록·상세 | 공식 서울열린데이터광장 서비스 `welfareServiceList`, `welfareServiceDe`. 코드의 `welfare_api_manifest.json` 참조 | 원문 응답과 파생 카탈로그 제외. 이용조건·본문 내 제3자 저작물의 권리 별도 확인 필요 |
| 행정경계·코드 | [통계청 행정구역 경계](https://www.data.go.kr/data/15129688/fileData.do), 2025년 2분기 고정 스냅샷을 사용한 기존 설정 | SHP/GeoJSON/대응표와 지도 생성 결과 제외. SGIS 자료와 서울시 격자 자료를 혼동하지 않음 |
| 주민등록인구 | [행정안전부 월별 연령별 인구](https://jumin.mois.go.kr/ageStatMonth.do), 월말 외국인 제외 기준 | 수집 코드만 포함. 실제 자료·캐시는 제외 |
| 지도·외부 라이브러리 | Folium 생성 Leaflet 리소스, 지도 타일, Plotly 등 | 설치 또는 브라우저에서 요청. 자체 복사본·이미지 미포함, 제공자 표시와 조건 확인 필요 |

외부 자료를 제외한 JSON 계약 파일에는 경로·스키마·입력 해시와 예상 행 수 같은 검증 메타데이터만 남습니다. 실제 관측값·개인 식별 정보·인증값은 포함하지 않습니다. `welfare_api_manifest.json`의 인증 상태는 **2026-10-23 조사 당시 기록**이며 현재 운영 상태를 뜻하지 않습니다.

공개 저장소의 코드만으로 대회 데이터를 취득할 수 없습니다. 권한 보유자는 별도의 승인된 경로로 자료를 전달받아야 합니다. 비공개 파일 저장소를 쓰더라도 지도·API 응답을 통해 대회 파생값을 공개하는 행위의 허용 여부는 별도 확인해야 합니다.

`config.example.json`의 기존 기본 경로와 실제 제공 폴더 구조가 다를 수 있습니다. 예를 들어 로컬 자료가 `데이터/0. 원본/전처리 데이터_통합본`에 있으면 비공개 실행 설정에서 경로를 지정합니다. 원본 이동으로 예제에 맞추거나 공개 저장소에 자료를 복사하지 마세요.
