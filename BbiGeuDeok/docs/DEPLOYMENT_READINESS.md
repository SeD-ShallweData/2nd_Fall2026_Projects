# 무료 배포 사전 점검 — 미배포

이 단계에서는 배포와 UI 개편을 수행하지 않습니다. 무료 서비스에 올릴 최종 아키텍처도 아직 결정하지 않았습니다.

| 항목 | 현재 구조와 후속 조치 |
|---|---|
| 네트워크 진입점 | 표준 `http.server`, loopback 바인딩, 로컬 Host/Origin. 외부 공개용 서버·TLS 프록시·허용 출처를 별도 설계하고 검증해야 함 |
| 자료 공개 권한 | 대회 원본과 파생값의 외부 공개 범위 미확인. 비공개 저장소에 보관해도 공개 API·지도 응답 권한이 생기지 않음. 실데이터 서비스의 선행 BLOCKER |
| 필수 자료 배치 | 공개 GitHub 복제만으로 서버 기동 불가. 권한 있는 자료를 비공개 빌드/런타임 경로로 배치하고 접근·응답 범위를 검토해야 함 |
| 캐시 이식 | 경로·mtime·입력 상태·코드 해시 고정 검사. 다른 머신으로 복사한 캐시가 거부될 수 있어 대용량 재처리 없이 안전한 이식 절차 필요 |
| 복지 API 캐시 | 디스크 372,429,722바이트. JSON 전체 파싱의 시작 메모리와 시간이 발생. 메모리 projection은 raw를 덜어도 첫 전체 검증 비용은 남음 |
| 읽기·쓰기 | 입력과 검증된 canonical 자료는 읽기용. import 시 `outputs/validation/p0_runtime` 생성과 Matplotlib 캐시 쓰기 필요. 관리자 갱신은 원자 교체용 임시파일·쓰기 잠금 필요 |
| 서버 예산 | 현재 LLM 12회/60초·프로세스 수명 120회. 재시작/다중 worker/계정 전체 한도는 아님. 공용 서버에는 인증·요청 제한·지출 상한·실패 대응 필요 |
| 비밀값 주입 | 서버 환경변수 또는 비공개 파일. 이미지·Git·프론트엔드·빌드 로그에 포함 금지 |
| 서울시 갱신 | 현재 공식 HTTP8088과 명시적 관리자 예외가 존재. 공용 운영 전 검증된 HTTPS 경로·갱신 정책 필요 |
| 프론트엔드 | Folium 생성 Leaflet 및 부속 CDN·지도 타일의 네트워크·출처 표시·정책 확인 필요. 정적 HTML만 분리하면 Python API가 동작하지 않음 |
| 무료 환경 | 메모리·임시 디스크·절전/콜드 스타트·쓰기 가능 경로·요청 시간제한·공간 패키지 설치가 실제 제한에 맞는지 실측 필요 |

STEP 2의 Windows 새 프로세스에서 읽기 전용 로더를 실측했습니다. 서비스 자료 로딩 약 4.24초, 작업 집합 약 372MB였습니다. 전체 복지 API 캐시의 첫 검증은 약 20.86초이며 이 과정의 **최대 작업 집합은 약 3.95GB**였습니다. 검증 후 약 463MB로 줄었지만 시작 시 피크가 남습니다. HTTP 서버·LLM 호출·실제 동시 요청은 측정하지 않았습니다. 이 피크를 감당할 수 없는 무료 환경은 현재 구조로 실행할 수 없으므로, 원문과 서비스 인덱스 분리 및 읽기 방식 개선을 후속 단계에서 검증해야 합니다. 이번에는 원본 캐시를 수정하지 않았습니다.

원문 이미지·HTML을 제거한 서비스 전용 최소 복지 인덱스는 권리 확인 후 검토할 수 있는 후보입니다. 이번 단계에서는 기존 372MB 캐시를 변경하지 않았습니다. 민감한 대회 데이터를 공개 GitHub/LFS나 다운로드 API로 우회 전달하지 않습니다.

무료 공급자별 한도와 가격 정책은 변동하므로 현재 구조를 확인하기 전 특정 플랫폼에서 실행 가능하다고 보장하지 않습니다. 필요한 데이터·공개 응답 권한, 메모리 측정, 운영 서버와 인증·영속 예산이 다음 단계의 결정 항목입니다.
